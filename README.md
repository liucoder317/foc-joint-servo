# foc-joint-servo：单关节 FOC 伺服驱动器

> 草稿。项目处于 M0（建工程），还没有可运行的功能。

在 STM32G431 三相驱动板上用 C 手写 FOC，带电流环、速度环、位置环、故障保护和 CAN 指令接口，驱动一台 24 V 永磁同步电机（PMSM）作为单个关节。不使用 MCSDK 或代码生成工具产生的控制代码。

## 硬件

| 部件 | 说明 |
|---|---|
| 驱动板 | STM32G431CBU6；FD6288T 栅极驱动；60 V MOSFET；3 路 5 mΩ 采样电阻，片内运放放大；SIT1050T CAN 收发器；输入 18～38 V（型号待补） |
| 电机 | 42EM64 PMSM：24 V，额定 4 A，0.15 N·m，4000 rpm，4 对极，相电阻 0.23 Ω，相电感 0.08 mH |
| 编码器 | 电机自带，SPI（KTH7823）和 ABZ（1024 线）两种接口 |
| 电源 | 24 V 5 A 适配器 |
| CAN 适配器 | PCAN-USB 兼容模块，经典 CAN |
| 调试 | Keil MDK 调试器、24 MHz 逻辑分析仪 |

## 编译和烧录

环境：Keil MDK 5.38（Arm Compiler 6），STM32CubeMX 6.18.1，STM32Cube FW_G4 V1.6.3。

1. 用 Keil 打开 `firmware/MDK-ARM/firmware.uvprojx`。
2. 按 F7 编译。
3. 接好调试器，按 F8 下载。

## 安全

- 调闭环前先完成过压保护和硬件过流封波。
- 开环电压从 0.3～0.5 V 开始。原因：堵转时电流约为 0.5 V ÷ 0.23 Ω ≈ 2.2 A。
- 持续电流不超过 4 A。
- 逻辑分析仪的地夹只接驱动板 GND。
